Catatan skema:
001_initial_schema.sql adalah skema awal untuk project Supabase BARU yang belum pernah menjalankan migration sebelumnya.
Jika schema email-login sebelumnya sudah dijalankan di Supabase, JANGAN jalankan ulang file ini. Buat migration ALTER TABLE terpisah setelah memeriksa kondisi database.

Setelah file disalin:
1. node --check .\api\garment.js
2. node --check .\scripts\import-legacy-data.mjs
3. npm.cmd run migrate:legacy

Perintah migrate:legacy hanya preflight selama tidak ada argumen --apply.
Jangan jalankan --apply sampai preflight lolos, project Supabase disiapkan, dan backup terverifikasi.

Supabase Auth tetap menggunakan email internal yang dibuat otomatis dari ID_User.
Karyawan tidak memasukkan alamat email. Password lama dikirim dari CSV lokal ke Supabase Auth untuk di-hash.
